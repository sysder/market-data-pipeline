# 決定

ファンディングレートと建玉スナップショットを取得する

# 理由

- 後から取得することができないデータを取得するため
- 出来高やOHLCVは後で遡って取得可能なので必要になったら取得する

# 備忘録

- 建玉スナップショットは過去30日であれば遡って取得可能であるが、5分足の要約データになる（periodパラメータの選択肢が5m,15m,30m,1h,...,1d で、5分より細かい指定が存在しない）
    - 60日前を指定すると`{"msg":"parameter 'startTime' is invalid.","code":-1130}`と返ってきた
        - 上記のコマンド：`curl "https://fapi.binance.com/futures/data/openInterestHist?symbol=BTCUSDT&period=1d&startTime=$(date -v-60d +%s)000&endTime=$(date -v-55d +%s)000"`
    - 10日前を指定すると`[{"symbol":"BTCUSDT","sumOpenInterest":"100362.59500000","sumOpenInterestValue":"6248314221.95300000","CMCCirculatingSupply":"20053409.00000000","timestamp":1783555200000},{"symbol":"BTCUSDT","sumOpenInterest":"100146.65100000","sumOpenInterestValue":"6329051472.72400900","CMCCirculatingSupply":"20053853.00000000","timestamp":1783641600000}]`と返ってきた
        - 上記のコマンド：`curl "https://fapi.binance.com/futures/data/openInterestHist?symbol=BTCUSDT&period=1d&startTime=$(date -v-10d +%s)000&endTime=$(date -v-8d +%s)000"`
